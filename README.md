## 🔒 隐私保护

### .gitignore 配置
已配置 `.gitignore` 文件，以下内容**不会**被Git追踪：
- `private/` 文件夹
- 所有 `*_私密版.md` 文件
- 数据库文件（*.db）
- 日志文件（*.log）

### 上传GitHub前检查

运行以下命令检查哪些文件会被上传：

```bash
git status
```

确保不会出现：
- ❌ private/
- ❌ *_私密版.md
- ❌ *.db

## 🚀 快速开始

### 上传到GitHub

```bash
# 1. 初始化Git（如果还没做）
git init

# 2. 添加公开文件
git add public/
git add server/
git add README.md
git add .gitignore

# 3. 提交
git commit -m "上传CogniMate公开版本"

# 4. 推送到GitHub
git push origin main
```

### 本地私密文件备份

```bash
# 压缩私密文件夹备份
tar -czvf cognimate_private_$(date +%Y%m%d).tar.gz private/

# 保存到安全位置（如本地硬盘、加密U盘）
```
