## 第2页：项目背景

### 现代人的生活困境

在快节奏的都市生活中，我们面临着诸多健康挑战：

- **忙碌忘事**：工作一忙就忘记喝水、忘记运动
- **工具冰冷**：手机闹钟只会响，没有温度和陪伴
- **难以坚持**：独自健身缺乏动力，容易半途而废
- **缺乏调整**：身体不适时不知如何调整计划

### 我们的洞察

用户需要的不是一个冷冰冰的提醒工具，而是一个**有温度、懂陪伴、能调整**的智能伙伴。

### 四大痛点

| 痛点 | 具体表现 | 影响 |

### 传统方案的局限

- 手机闹钟：单一提醒，无法记录和分析
- 健身APP：功能复杂，缺乏情感连接
- 人工提醒：成本高，难以持续

## 第4页：解决方案

# CogniMate 智能提醒系统

## 核心功能

### 🕐 定时提醒
- 每天7次喝水提醒（9:30-17:00）
- 晚间运动提醒（19:00）
- 工作日上班提醒（7:50）

### 📝 打卡记录
- 每次完成可回复打卡
- 自动统计完成率
- 形成习惯数据

### 🎯 目标追踪
- 减重目标分解为每日任务
- 进度可视化
- 阶段性成果庆祝

### 💬 情感支持
- 根据情绪调整语气
- 失败时给予鼓励
- 成功时真诚庆祝

### 系统架构图

```
┌─────────────────────────────────────────┐
│           用户交互层（飞书）               │
│         消息接收 / 回复 / 打卡            │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│           OpenClaw Gateway              │

└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│         CogniMate 智能引擎              │
```

### 技术特点

- **本地部署**：数据存储在用户设备，隐私安全
- **飞书集成**：基于飞书机器人，交互自然
- **智能分析**：情感分析、动态调整
- **可扩展**：支持多种提醒类型和场景

## 第6页：核心功能展示

### 1. 智能喝水提醒

**提醒时间**：
- 9:30 - 第1杯：早晨补水
- 10:30 - 第2杯：工作间隙
- 11:30 - 第3杯：午饭前控制食欲
- 14:00 - 第4杯：午休后清醒
- 15:00 - 第5杯：下午茶时间
- 16:00 - 第6杯：工作间隙
- 17:00 - 第7杯：下班前补水

**特色**：每次提醒带打卡提示，累计完成率统计

### 2. 运动计划管理

**30分钟减重计划**：
- 热身：5分钟
- 有氧：10分钟
- 瘦腿：8分钟
- 瘦肚子：5分钟
- 拉伸：2分钟

**游泳学习**：每周2次，每次45-60分钟

### 3. 动态调整

- 状态不佳 → 建议减少强度
- 身体不适 → 建议休息
- 精力充沛 → 可增加强度

## 第8页：创新点

### 四大创新

#### 1. 本地部署
- 所有数据存储在用户本地设备
- 不上传云端，隐私绝对安全
- 响应速度快，不依赖网络

#### 2. 情感智能
- 不只是提醒，还有温度
- 根据用户情绪调整语气
- 失败时鼓励，成功时庆祝

#### 3. 闭环管理
- 提醒 → 执行 → 打卡 → 反馈 → 调整
- 完整闭环，持续优化
- 数据驱动，科学管理

#### 4. 持续学习
- 记录用户反馈和偏好
- 不断优化提醒策略
- 越用越懂你
